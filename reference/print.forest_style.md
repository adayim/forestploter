# Print a forest plot style

Show the settings of a style that are not the default ones.

## Usage

``` r
# S3 method for class 'forest_style'
print(x, ...)
```

## Arguments

- x:

  A style created with
  [`forest_style`](https://adayim.github.io/forestploter/reference/forest_style.md).

- ...:

  other arguments not used by this method

## Value

Invisibly returns the style.
